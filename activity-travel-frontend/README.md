# Activity Travel Frontend

Next.js frontend with a separate `src` directory.

## Structure

```text
activity-travel-frontend/
└── src/
    ├── app/
    ├── components/
    ├── lib/
    └── types/
```

## Setup

```bash
cp .env.example .env.local
npm install
npm run dev
```

Frontend:

- http://localhost:3000
